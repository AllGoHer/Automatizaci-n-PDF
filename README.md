# Automatización-PDF
Generador de texto a PDF a traves de vetana generada en el localhost
en este caso generaremos algunos minicuentos para convertirlos a PDF, en el cual puedes ingresar el nombre del autor, los capitulos y el cuerpo (texto) del cuento y, luego se guardará en una carpeta.
